# Финансовый помощник Team Tracker

Личные финансы: `/v2/personal/finance` и чат `/v2/personal/finance/assistant` (режим «Финансы»).
Планирование недели — отдельный skill `teamtracker-day-plan` (режим «План дня» в том же чате).

## Когда использовать

- «заработал N», «доступно N», «куда класть», «разложи по фондам»
- Вопросы про подушку, одежду, подарки, сюрпризы Лере, свободные деньги
- После явного «запиши / занеси / одобряю» — запись в фонды
- Если речь про неделю/стратегию/свидание/выходной — используй `teamtracker-day-plan`, не этот skill

## Правила (кратко)

1. Зарплата бизнеса 50 000 ₽ — отдельно (не в этом распределении).
2. Платежи жизни 93 000 ₽.
3. Экономный месяц 170 000 = 93к платежи + 77к свободные (целевые фонды не пополнять).
4. Нормальный от 200 000 = 93к + 87к свободные + одежда 5к + подарки 10к + Лера 5к.
5. Сверх 200 000: **80% подушка/капитал**, **20% свободные**.
6. Горизонт до **1 октября 2027**: стабильные **400 000 ₽/мес** и капитал **1,8–2,4 млн ₽**.
7. Платежи и свободные **не пишутся в фонды** скриптом — только подсказка. В фонды идут clothing / gifts / lera / cushion.

## Вызов

```bash
# Контекст фондов
python3 /root/.openclaw/workspace/skills/teamtracker-finance/finance.py --context

# Только план
python3 /root/.openclaw/workspace/skills/teamtracker-finance/finance.py \
  --message "заработал 250 тысяч"

# Или сумма явно
python3 .../finance.py --available 250000

# Запись — ТОЛЬКО после явного одобрения пользователя
python3 .../finance.py --available 250000 --apply
```

## Поведение

1. В личном чате с Николаем, если речь про доход/фонды — сначала `finance.py --message "..."`.
2. Покажи режим (слабый / эконом / нормальный) и строки распределения.
3. Спроси подтверждение, прежде чем `--apply`.
4. Если stdout `OK: записано` — коротко подтверди, что изменилось.
5. Если `ERROR:` — скажи об ошибке, не выдумывай суммы.
6. Не меняй правила 80/20 и пороги 170к/200к.

## Пример ответа

«Нормальный режим при 250 000. Платежи 93к, свободные 97к (87к + 20% сверх), одежда 5к, подарки 10к, Лера 5к, подушка 40к. Записать в фонды?»

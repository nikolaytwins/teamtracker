# Планирование недели Team Tracker

Чат: `/v2/personal/finance/assistant` → режим «План дня».
Календарь: `/v2/agency/plan`.

## Когда использовать

- «распланируй неделю», «раскидай дни», «куда поставить стратегию»
- стратегия / творчество / выход в люди / свидание с Лерой / выходной
- рабочие дни по 4 часа (минимум 3)

## Правила недели

1. 1 стратегический день (блок 3–4 ч, можно с мероприятиями)
2. 1 творческий блок 3–4 ч (можно с мероприятиями)
3. 1 выход в люди (мероприятие / нетворкинг)
4. 1 день под свидание с Лерой
5. 1 полный выходной
6. ≥3 полноценных рабочих дня по 4 часа

## Вызов

```bash
python3 /root/.openclaw/workspace/skills/teamtracker-day-plan/day_plan.py --context

python3 .../day_plan.py --message "распланируй неделю, свидание в субботу"

# Запись — ТОЛЬКО после явного одобрения
python3 .../day_plan.py --message "распланируй неделю" --apply
```

## Поведение

1. Если речь про неделю/дни/стратегию/свидание — сначала `day_plan.py --message "..."`.
2. Покажи чеклист и дни.
3. Спроси подтверждение перед `--apply`.
4. После `OK: записано в план` — коротко подтверди.
5. Не пиши в календарь без явной команды «запиши / занеси / одобряю».

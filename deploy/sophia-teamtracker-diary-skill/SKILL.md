# Дневник Team Tracker

Записи попадают в `/v2/personal/observations` (личный дневник).

## Когда использовать

- Сообщение заканчивается **строкой только с хештегами**: `#работа` (API сам сопоставит с `#👨🏻‍💻 работа`, если такой тег уже есть)
- Начинается с **`дневник:`**
- Николай просит **записать в дневник под существующим тегом**, не зная точное название/эмодzi

## Существующие теги (важно)

Теги в Team Tracker **уже с эмодzi** (`🔥 само возвращается`, `👨🏻‍💻 работа`, `❤️ отношения` …).
**Не придумывай новый тег**, если подходит существующий.

1. Если тег назван неточно — сначала посмотри каталог:
   ```bash
   python3 /root/.openclaw/workspace/skills/teamtracker-diary/diary.py --list-tags
   ```
2. Запиши с подсказкой (API сопоставит сам):
   ```bash
   python3 /root/.openclaw/workspace/skills/teamtracker-diary/diary.py \
     --body "текст записи" \
     --tag-hints "работа"
   ```
   Или с полным сообщением:
   ```bash
   python3 .../diary.py --message "дневник: сегодня много кодил" --tag-hints "работа"
   ```

## Обычный вызов (как раньше)

```bash
cd /root/.openclaw/workspace
python3 skills/teamtracker-diary/diary.py --message "<текст сообщения пользователя целиком>"
```

## Поведение

1. **Перед обычным ответом** в личном чате с Николаем — если это дневник, выполни скрипт.
2. Если просят «под тегом про X» без точного имени — **`--list-tags`** при необходимости, затем **`--tag-hints "X"`**.
3. Если stdout **`OK:`** — коротко подтверди запись и **повтори финальные теги** из ответа API.
4. Если **`ERROR: неоднозначный тег`** — спроси уточнение (например «энергия плюс или минус?»).
5. Если **`ERROR: не нашла тег`** — покажи 5–8 тегов из `HINT:` или `--list-tags`.
6. **`SKIP:`** — не дневник, продолжай как обычно.
7. Новый тег создавай **только если Николай явно просит новый тег** — тогда добавь `--allow-new-tags`.

## Формат заметки

```
Сегодня закрыл важную задачу по проекту, чувствую спокойствие.

#работа
```

Строка `#работа` сопоставится с существующим `👨🏻‍💻 работа`, если он есть в каталоге.
